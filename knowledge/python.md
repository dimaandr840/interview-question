# 500 вопросов для собеседования Python Backend Developer

База содержит 500 вопросов по десяти темам: Junior — 200, Middle — 200, Senior — 100. Разборы структурированы по принципу работы, практике и типичным ошибкам. Каждый вопрос Senior предлагает обсудить компромиссы, риски и критерии выбора: единственного универсального решения нет.

Вопросы разбиты на 10 файлов по темам (папка `python-backend-developer/`), чтобы каждый файл оставался удобного размера.
