# 500 вопросов для собеседования Data Analyst

База содержит 500 вопросов по десяти темам: Junior — 200 (40%), Middle — 200 (40%), Senior — 100 (20%). Внутри каждой темы соблюдается то же соотношение 40%/40%/20%. Каждый вопрос включает короткий ответ, разбор (как это работает / на практике / частые ошибки) и пример/кейс с SQL- или Python-кодом, таблицей синтетических данных или мини-кейсом. Каждый вопрос уровня Senior явно отмечает, что единственного правильного решения может не быть, и добавляет пункт «Компромисс» с обсуждением издержек, рисков и критериев выбора.

Вопросы разбиты на 10 файлов по темам (папка `04-data-analyst/`), чтобы каждый файл оставался удобного размера. Нумерация вопросов сквозная (1–500) по всем файлам, ID вопроса имеет формат `Q-04-<тема>-<номер>`, например `Q-04-01-0001`.
