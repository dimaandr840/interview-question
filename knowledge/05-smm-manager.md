# 500 вопросов для собеседования SMM Manager

База содержит 500 вопросов по одиннадцати темам: Junior — 200 (40%), Middle — 200 (40%), Senior — 100 (20%). Внутри каждой темы соблюдается то же соотношение 40%/40%/20%. Каждый вопрос включает короткий ответ, разбор (как это работает / на практике / частые ошибки) и пример/кейс — фрагмент поста, брифа, контент-плана, настройки рекламной кампании, шаблона ответа на негатив или расчёт метрики. Каждый вопрос уровня Senior явно отмечает, что единственного правильного решения может не быть, и добавляет пункт «Компромисс» с обсуждением издержек, рисков и критериев выбора.

Вопросы разбиты на 11 файлов по темам (папка `05-smm-manager/`), чтобы каждый файл оставался удобного размера. Нумерация вопросов сквозная (1–500) по всем файлам, ID вопроса имеет формат `Q-05-<тема>-<номер>`, например `Q-05-01-0001`.
